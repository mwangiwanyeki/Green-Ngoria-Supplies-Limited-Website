# DESIGN.md --- Green Ngoria Supplies Limited

## Premium Mining & Mining-Plant Engineering Experience

### 1. Design objective

Design Green Ngoria as a **premium B2B mining engineering, mineral
processing and mining-plant construction company**, not as a generic
supplies website and not as a generic SaaS dashboard.

The visual language should communicate: - engineering precision - heavy
industry - mineral processing - construction capability - safety -
reliability - technical competence - East African operational reach -
professional corporate governance - modern technology

The company profile states that Green Ngoria has operated for more than
10 years and combines engineering, construction, gold mining,
specialized erection and supplies expertise.

### 2. Brand hierarchy

Primary: **Mining & Mineral Processing**

Secondary: **Mining Plant Engineering & Construction**

Supporting: **Mechanical & Electrical Engineering** **Equipment &
Supplies** **Civil & Infrastructure** **Operations, Maintenance &
Support**

Do not let legacy/general-supply categories dominate the homepage.

### 3. Visual identity

Use the existing Green Ngoria green identity with: - deep/industrial
green - controlled emerald/green accents - charcoal/near-black - white -
neutral industrial surfaces - restrained semantic colors

Avoid excessive neon green.

Use subtle industrial textures, technical grids, process-line motifs and
engineering diagrams only where they improve comprehension.

### 4. Typography

Use a modern professional sans-serif.

Hierarchy: - Display - H1 - H2 - H3 - H4 - Body - Label - Caption -
Data/metric

Use tabular numerals for technical measurements, project figures, dates
and commercial values.

### 5. Homepage structure

Recommended premium structure:

1.  Hero --- Mining & Mining Plant Engineering
2.  Trust/credibility strip
3.  Core mining capabilities
4.  Gold processing / CIP / CIL expertise
5.  Mining plant design → construction → commissioning lifecycle
6.  Technical plant assessment CTA
7.  Equipment & spares marketplace
8.  Featured projects
9.  Engineering and construction capabilities
10. HSE / sustainability / quality
11. East Africa reach
12. Technical insights
13. Client CTA
14. Footer

Hero CTAs: **Request Plant Assessment** **Discuss a Mining Project**
**Request a Quote** **Explore Equipment**

### 6. CIP/CIL visual storytelling

Build interactive but technically credible process representations: -
crushing - grinding - classification - leaching - adsorption -
elution/recovery - tailings - water/reagent/utilities context

Use animated flow lines and process-stage highlighting.

Never imply an exact process design without engineering data.

### 7. Mining project visual system

Project cards should show: - project type - location - stage - scope -
engineering/construction disciplines - status - completion year where
verified

Do not invent project metrics.

### 8. Equipment design

Equipment cards should emphasize: - equipment category - application -
specifications - availability status - technical documents - RFQ CTA

Use technical comparison layouts rather than consumer e-commerce
patterns.

### 9. Plant assessment experience

Use a premium multi-step assessment interface: **Project → Site →
Mineral → Existing Plant → Process → Equipment → Performance →
Challenges → Attachments → Review**

Show: - completion percentage - autosave - technical hints - upload
progress - validation - privacy notice - next-step expectation

### 10. Client portal design

Client portal should feel like a project command center.

Dashboard: - project health - progress - milestone timeline - approvals
awaiting client action - documents - quotations - invoices -
procurement - commissioning - support - notifications

### 11. Admin design

Admin is information-dense but polished: **Context → Filters → KPIs →
Priority actions → Operational tables → Analytics → Activity**

Key dashboard areas: - CRM pipeline - technical assessments - RFQs -
quotations - active projects - procurement - construction -
commissioning - HSE - finance - assets/maintenance - website CMS

### 12. Advanced component library

Build reusable components for: - enterprise navigation - mega menu -
command palette - breadcrumbs - stepper - project timeline - milestone
tracker - KPI cards - technical metric cards - equipment cards - RFQ
builder - quotation builder - comparison tables - engineering document
viewer - revision timeline - approval workflow - audit timeline -
Kanban - calendar - charts - maps - status badges - file uploaders -
rich-text editor - media manager - drawers/dialogs - skeletons - empty
states - error states

### 13. Mining domain components

Dedicated visual components: - ProcessFlowDiagram - CIPProcessMap -
CILProcessMap - PlantStageCard - EquipmentSpecPanel -
PlantAssessmentStepper - AssessmentFindingCard -
OptimizationRecommendation - ProjectPhaseTimeline -
ConstructionProgress - CommissioningChecklist - PunchList -
HSEIncidentCard - AssetTimeline - MaintenanceSchedule - WarrantyTracker

### 14. Motion and Framer Motion

Use Framer Motion for: - hero reveal - process-flow animation - section
reveal - card hover - timeline progression - modal/drawer transitions -
notification transitions - progress indicators - accordion expansion -
dashboard state transitions

Use: - 120--180ms for micro-interactions - 180--280ms for normal UI -
280--450ms for emphasis

Support `prefers-reduced-motion`.

No decorative animation should interfere with: - quotation submission -
approval - financial actions - HSE reporting - commissioning sign-off

### 15. Animated icon system

Use a consistent icon family.

Animate icons for meaningful states: - upload - processing -
synchronization - success - warning - maintenance - approval -
notification - document revision

Avoid continuously animated icons that create visual noise.

### 16. Responsive behavior

Mobile: - action-first - simplified navigation - readable technical
cards - touch-friendly forms

Tablet: - adaptive operational layouts

Desktop: - multi-panel engineering and operational workflows

Do not simply squeeze large data tables onto mobile.

### 17. Accessibility

Target WCAG 2.2 AA: - semantic HTML - keyboard navigation - visible
focus - accessible labels - contrast - screen-reader support - no
color-only status - reduced motion - accessible modals/tables/forms

### 18. Premium visual effects

Use: - layered surfaces - subtle gradients - controlled shadows - image
masking - technical linework - restrained glass effects - process
diagrams - depth and parallax only where useful

Avoid generic AI/SaaS aesthetics.

### 19. Content hierarchy

Every page should answer: 1. What does Green Ngoria do? 2. Why is it
technically credible? 3. What evidence supports it? 4. What can the
visitor/client do next?
